BUNDLED SYSTEM LIBRARIES (Linux AppImage only)
================================================================================

The Linux .deb and .rpm packages declare their GUI/runtime libraries as system
dependencies and bundle none of them - this section does not apply to those.

The Linux AppImage is self-contained and therefore redistributes copies of the
GTK / WebKitGTK runtime stack and its transitive dependencies. Several of these
libraries are licensed under the GNU Lesser General Public License (LGPL), v2.1
or v3, or are dual-licensed with the LGPL as one option, including:

    GLib / GObject / GIO, GdkPixbuf, GTK 3, GDK, Pango, Cairo, ATK / at-spi2,
    librsvg, WebKitGTK (libwebkit2gtk-4.1) and JavaScriptCore (libjavascriptcoregtk-4.1),
    libsoup 3, libsecret, GStreamer core and the base/good plugin sets,
    GnuTLS, Nettle / Hogweed, libidn2, libunistring, libtasn1, p11-kit,
    libgcrypt / libgpg-error, libseccomp, libcap, elfutils (libdw / libelf),
    libmount / libblkid / libudev / libsystemd, libenchant, libmanette, libepoxy.

These libraries are used unmodified and are linked dynamically. The LGPL permits
this redistribution. In accordance with the LGPL:

  * The libraries are dynamically linked and may be replaced by the user by
    substituting compatible shared objects inside the extracted AppImage.

  * The complete corresponding source code for every bundled library, at the
    exact versions shipped, is the stock packaging from Ubuntu 22.04 LTS
    ("jammy"). It can be obtained from:

        https://packages.ubuntu.com/jammy/    (per-package "source" links)
        apt-get source <package>              (with deb-src enabled on jammy)
        http://archive.ubuntu.com/ubuntu/pool/main/
        http://archive.ubuntu.com/ubuntu/pool/universe/

    A written request for the source of any bundled library may also be sent to
    the address in the copyright notice above; it will be honoured for three
    years from the date this build was distributed.

  * The full text of the GNU LGPL v2.1 is available at
    https://www.gnu.org/licenses/old-licenses/lgpl-2.1.txt and the GNU LGPL v3
    at https://www.gnu.org/licenses/lgpl-3.0.txt . On a Debian/Ubuntu system the
    per-library license texts are also installed under
    /usr/share/doc/<package>/copyright .

The remaining bundled libraries (zlib, libpng, libjpeg-turbo, libwebp, libtiff,
FreeType, HarfBuzz, fontconfig, pixman, libxml2, libxslt, PCRE2, SQLite, ICU,
brotli, the X11 client libraries, Wayland client libraries, and others) are
under permissive licenses (MIT, BSD, zlib, and similar) with attribution-only
